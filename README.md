# 🍺 Munich Knowledge Quiz 🥨

**Servus!** Think you know Munich? This quiz is for locals who want to test their knowledge and discover new spots in the city.

## What is this?

An interactive web quiz designed for people who already live in Munich but want to get to know the city better. Answer 6 questions (different every time!) and get personalized recommendations for Munich sights, hidden gems, beer gardens, and local experiences.

## Features

- **20+ Questions** covering:
  - Famous sights
  - Hidden gems
  - History & culture
  - Food & beer gardens
  - Neighborhoods
  - Local quirks & Bavarian life

- **Randomized every time**: Different questions, shuffled answers, varied question types
- **Smart recommendations**: Based on your score AND what you got wrong/right
- **Cheeky Munich attitude**: Written like a local teasing their friends
- **Fully responsive**: Works on mobile and desktop

## How to Use

1. Open `index.html` in your browser
2. Click "Los geht's!" to start
3. Answer 6 questions
4. Get your score, verdict, and personalized Munich to-do list!

## Tech Stack

- Pure HTML, CSS, and JavaScript (no frameworks needed)
- Bavarian blue & white theme
- Responsive design
- Local storage ready (future feature)

## Local Development

Just open `index.html` in any modern browser. No build process needed!

```bash
# If you want to run a local server:
python3 -m http.server 8000
# Then visit http://localhost:8000
```

## Deploy to GitHub Pages

1. Go to your repository settings
2. Navigate to **Pages** section
3. Under "Source", select your branch (e.g., `main` or `claude/munich-quiz-app-...`)
4. Click Save
5. Your quiz will be live at: `https://[username].github.io/MunichKnowledge/`
